Thank you for purchasing VoxLeaders, a premier multipurpose HTML5/CSS/JavaScript template and web application designed specifically for youth academies, debate camps, leadership institutions, and EdTech platforms.

2. Core Highlights & Technologies

Instant Dark Mode Built on Bootstrap 5.3 data-bs-theme engine with localStorage persistence and CSS custom properties.
Bidirectional LTR & RTL Dynamic stylesheet swapping between bootstrap.min.css and bootstrap.rtl.min.css plus custom rtl.css.
Parent Portal Dashboard Includes complete interactive dashboard views with radar charts, session booking, and photo vault.
Pure Vanilla JavaScript Zero heavy jQuery runtime dependencies. Fast 100/100 Lighthouse performance score ready.

4. Customizing Theme Colors & Fonts

All master tokens are defined in assets/css/style.css inside the :root declaration: 

:root {
  --vx-primary: #4F46E5;       /* Electric Indigo */
  --vx-secondary: #0B132B;     /* Deep Navy */
  --vx-accent: #6366F1;        /* Soft Iris Indigo */
  --vx-success: #4F46E5;       /* Electric Indigo */
  --vx-font-sans: 'Plus Jakarta Sans', sans-serif;
  --vx-font-heading: 'Outfit', sans-serif;
}

5. Chart.js Customization

Chart setups are modularly initialized in assets/js/dashboard.js:

  • skillRadarChart: 6-metric radar chart tracking speech variety, confidence, and posture.
  • weeklyGrowthChart: Bar chart tracking weekly progress over 6 weeks.
  • adminRevenueChart: Dual-axis line chart for revenue ($k) and camper enrollments.
