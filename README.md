# VoxLeaders - Youth Leadership & Public Speaking Camp
> **Commercial-Grade Multipurpose HTML5/CSS/JavaScript Template & Web Application**  
> Designed for high-value sales on marketplaces like ThemeForest as well as custom client deployments.

---

## 🌟 Live Demo & Brand Case
- **Brand Name**: **VoxLeaders** (Youth Leadership & Oratory Academy)
- **Tone**: Confident, aspirational, encouraging, professional, and accessible.
- **Framework**: Bootstrap 5.3.3 + Vanilla JavaScript + Chart.js 4.4.2 + SVG Vector Graphics.
- **Design System & Color Constancy**: Monochromatic Luxury Design System anchored on **Electric Indigo (`#4F46E5`)** with unified tonal variations (`#312E81`, `#3730A3`, `#4338CA`, `#6366F1`, `#818CF8`, `#EEF2FF`). All disparate multi-color badges, checkmarks, charts, and ribbons have been harmonized for strict single-color visual constancy.
- **Global Navigation Structure**: Streamlined header across all views: `Home` (dropdown with Home 2), `About Us`, `Services`, `Pricing`, `Gallery`, `Blog`, `Contact`, followed by `Dashboard` dropdown (Parent Portal & Admin Console) and `Sign Up` action button.
- **Theme Support**: Real-time **Dark Mode / Light Mode** switch + Bidirectional **LTR / RTL** toggle with persistence in `localStorage`.

## 🎨 Asset Architecture
- `assets/css/style.css` - Master Design System with CSS Custom Properties, typography, card styling, and dark mode overrides.
- `assets/css/rtl.css` - Dedicated bidirectional stylesheet for RTL Arabic/Hebrew layouts.
- `assets/css/dashboard.css` - Dashboard layout, sidebars, KPI widgets, split-pane chat interface, and data tables.
- `assets/js/main.js` - Theme Engine, RTL engine, sticky header, smooth back-to-top, counter animations, filter system, interactive toast notifications, countdown timer.
- `assets/js/dashboard.js` - Chart.js radar, bar, and line initialization, user roster filtering, live chat interaction, checkout calculator.
- `assets/img/brand/` - High-resolution SVG vector logos (`logo.svg`, `logo-white.svg`, `favicon.svg`).
- `assets/img/badges/` - Achievement badges (`badge-oratory.svg`, `badge-debate.svg`, `badge-confidence.svg`, `badge-diplomat.svg`).
- `assets/img/avatars/` - High quality character avatars (`avatar-1.svg` to `avatar-8.svg`).
- `assets/img/illustrations/` - Custom vector scene illustrations (`hero-oratory.svg`, `hero-saas.svg`, `404-speech.svg`, `coming-soon.svg`).

## 🚀 How to Run Locally

You can preview the application using any static web server:

```powershell
# Using Python
python -m http.server 8080

# Using Node.js
npx serve .
```

Open `http://localhost:8080/index.html` in your browser.
